# FloodPhys — Flood Vulnerability Mapping, Banyumas Regency

Machine‑learning pipeline for producing a **flood vulnerability map** of Kabupaten Banyumas (Central Java, Indonesia) from open geospatial data. Built for the CENTIVE 2026 conference paper.

---

## Overview

```
DEM tiles ──► mosaic & clip ──► slope, TWI, HAND ──► ┐
Rivers ──────► distance‑to‑river, drainage density ──► ├─► feature table ──► ML models ──► vulnerability map
WorldCover ──► land‑cover code ─────────────────────► ┘
Rainfall ────► annual mean ─────────────────────────► ┘
```

1. **Pre‑process** — mosaic 9 DEMNAS tiles, clip to county boundary, derive terrain rasters, compute river proximity, extract pixel values at flood/non‑flood sample points, spatial‑block split. Flood labels come from the BPBD inventory (35 records, 33 unique locations); each unique location is expanded to five samples (one at the recorded coordinate plus four jittered within a 200 m radius), giving 165 positives. Non‑flood points are generated by uniform sampling with a 2 km exclusion buffer around every positive, giving 165 negatives matched one‑to‑one. Train/test are separated by $0.05^{\circ}$ spatial blocks (train 266, test 64).
2. **Train & evaluate** — fit four classifiers (LogReg, Random Forest, XGBoost, LightGBM) with imbalance‑aware hyper‑parameters, report AUC / F1 / precision / recall / latency. AUC is computed as `roc_auc_score(y_test, P(flood=1))` and asserted equal to the trapezoid AUC used by the ROC plot.
3. **Visualise** — generate confusion matrices, ROC curves, feature importance chart, and the final vulnerability map. The best model is chosen dynamically by AUC, then F1‑macro.

## Dataset

All raw data are hosted on Google Drive:

> **[📂 Download Dataset](https://drive.google.com/drive/folders/1dGfy3hmHNI5i4xDqvG3oe6gSCQn_vdHM)**

| Layer | Source | Resolution |
|-------|--------|-----------|
| DEM | DEMNAS — BIG Indonesia | ~8 m |
| Land cover | ESA WorldCover 2021 v200 | 10 m |
| Rivers | HydroSHEDS HydroRIVERS v1.0 | vector |
| Boundary | geoBoundaries ADM2 (BPS / WFP / OCHA) | vector |
| Rainfall | BMKG Sta. Tunggul Wulung (monthly) | point |
| Flood points | BNPB + BPBD Banyumas (35 records, 33 unique, 2025) | point |
| Bencana stats | Open Data Kab. Banyumas (CKAN) | tabular |

## Quick Start

```bash
# 1. Clone & enter
git clone https://github.com/<user>/centive26.git && cd centive26

# 2. Create environment
python -m venv .venv && source .venv/bin/activate   # or .venv\Scripts\activate on Windows
pip install rasterio pysheds scipy shapely scikit-learn xgboost lightgbm joblib pandas matplotlib

# 3. Place raw data
#    Download from the Drive link above into Dataset/

# 4. Run pipeline
python Program/preprocess.py      # ~10 min — produces processed/ rasters + features.csv
python Program/Train.py           # ~30 s  — trains 4 models, saves .joblib & metrics
python Program/visualize.py       # generates figures & maps
```

## Results

Metrics from the latest spatial‑block evaluation (64 held‑out observations: 27 flood, 37 non‑flood):

| Model | AUC | Accuracy | F1 Flood (thr=0.5) | Precision | Recall | Latency (ms) |
|-------|-----|----------|-------------------|-----------|--------|-------------|
| Random Forest | **0.865** | **0.781** | 0.750 | 0.724 | 0.778 | 107.1 |
| XGBoost | 0.855 | 0.719 | 0.667 | 0.667 | 0.667 | 1.1 |
| Logistic Reg. | 0.821 | 0.781 | 0.774 | 0.686 | **0.889** | 0.3 |
| LightGBM | 0.813 | 0.719 | 0.625 | 0.714 | 0.556 | 2.1 |

The four AUC values (0.813–0.865) are statistically indistinguishable at this
test size: with 27 positive observations the standard error of an AUC near 0.85
is roughly 0.05. The ranking should not be read as a real ordering.

The susceptibility map is produced by random forest (best AUC, then F1‑macro).

Full table: `Outputs/tables/metrik_model.csv`
